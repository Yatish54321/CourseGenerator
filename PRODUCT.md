# Product Understanding - Course Generator

## 1. Business Problem

People who want to learn a new topic often find learning resources scattered across blogs, documentation,tutorials, ad videos. It is difficult to decide what to study first and how to progress from beginner to advanced. This product solves that problem by generating a structured learning roadmap from trusted sources.

Users often waste time deciding what to learn next because learning resources are scattered across multiple trusted sources.

---------


## 2. User Persona

### Who (Demographics)

- Students
- Software Developers
- Working Professionals
- Career switchers
- Anyone interested in learning a new technical topic

### How (Behavior)

- Searches for learning resources online.
- Uses blogs, documentation, and tutorials.
- Wants a structured learning path instead of random resources.

### Why (Motivation)

- Save time while learning.
- Learn topics in the correct order.
- Access trusted learning resources in one place.

### What (Product Category)

AI-powered course generation and learning roadmap platform.

----


## 3. Basic User Journey

1. Open the website.
2. Enter a topic (e.g., React, Docker, System Design).
3. The system fetches content from trusted websites using MCP connectors and retrieves relevant information.
4. AI organizes the content into the learning modules.
5. View the complete learning roadmap.
6. Explore references and recommended resources.
7. Export the roadmap as PDF or Markdown if needed.

-----


## 4. Feature Prioritization

### Must-Have Features

- Accept a topic name from the user.
- Fetch content from trusted websites.
- Generate a beginner-to-advanced course.
- Organise content into modules.
- Display learning objectives.
- Display reference links.
- Display module cards.
- Provide recommended reading order.
- Search functionality.
- Export to PDF/Markdown.

### Nice-to-Have Features

- User login and saved courses.
- Progress Tracking.
- Course sharing.
- Personalized recommendations.
- Dark mode.

### Rejected Features (Version 1)

- Live mentor support.
- Video hosting platform.
- Discussion forum.
- AI Resume Evaluator.
- AI Interview Coach.

These features increases complexity and are not required for the first version.

----


## 5. Inputs

The user provides:

- Topic name
- Export request (PDF/Markdown)

----


## 6. Outputs

The application returns:

- Structured learning roadmap
- Beginner-to-advanced curriculum
- Module Cards
- Topic hierarchy
- Learning objectives
- Reference links
- Recommended Reading Order
- Search functionality
- Exportable PDF/Markdown
