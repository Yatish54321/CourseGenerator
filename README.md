# Course Generator

## Summary

Build a website that creates a complete learning roadmap on any topic by collecting information from multiple trusted sources (blogs, documentation, tutorials, etc.) and organizing it into a beginner-to-advanced course with modules, learning objectives, recommended resources, and references.

**Example:** Generate a course on **System Design**, **Low-Level Design**, **React**, or **Docker**.

## Input Requirements

Users enter a topic name; the application fetches content from trusted websites using MCP connectors and retrieves relevant information using RAG.

## Deliverable

A website displaying the generated curriculum with module cards, topic hierarchy, learning objectives, reference links, recommended reading order, search functionality, and export to PDF/Markdown.
